# Aula 01 — Apresentação da Disciplina e Contextualização

Na primeira aula foi apresentada a disciplina de **Frameworks Front-end**, seus objetivos, conteúdos, metodologia e formas de avaliação.

Também foram introduzidos conceitos básicos de desenvolvimento Front-end, que é a parte da aplicação com a qual o usuário interage diretamente.

Foram apresentados temas como:

- HTML, CSS e JavaScript;
- JavaScript Vanilla;
- Git e GitHub;
- Versionamento e deploy;
- React;
- Vue;
- Angular;
- Componentização;
- Integração com APIs.

Ao longo da disciplina, o objetivo será aprender a desenvolver interfaces modernas, utilizar frameworks Front-end e publicar aplicações na Web.

A primeira atividade proposta é desenvolver um projeto utilizando **HTML, CSS e JavaScript**, versioná-lo no GitHub e realizar o deploy utilizando a Vercel.
