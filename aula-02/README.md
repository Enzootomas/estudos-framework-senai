# Aula 02 — Configuração do Ambiente de Desenvolvimento

Na Aula 02 foram apresentados os principais recursos utilizados para configurar um ambiente de desenvolvimento Front-end.

Os principais assuntos estudados foram:

* Versionamento de código;
* Versionamento Semântico (SemVer);
* Git e GitHub;
* Tags e boas práticas com Git;
* Visual Studio Code;
* Node.js;
* NPM;
* Criação de projetos React;
* Deploy utilizando Vercel.

O **Git** é utilizado para controlar as versões de um projeto, permitindo acompanhar alterações e recuperar versões anteriores.

Também foi apresentado o **Versionamento Semântico**, que utiliza o padrão `MAJOR.MINOR.PATCH` para identificar diferentes versões de um software.

O **Node.js** permite executar JavaScript fora do navegador, enquanto o **NPM** é utilizado para instalar e gerenciar bibliotecas e dependências dos projetos.

Na parte prática, foi demonstrada a criação de uma aplicação **React**, seu versionamento utilizando Git e GitHub e posteriormente o deploy da aplicação utilizando a **Vercel**.
