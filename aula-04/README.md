# Aula 04 — Consumindo APIs no Front-end

Na Aula 04 foram apresentados os principais conceitos relacionados ao consumo de APIs no desenvolvimento Front-end.

Os principais assuntos estudados foram:

- API;
- Protocolo HTTP;
- Métodos GET, POST, PUT, PATCH e DELETE;
- Endpoints;
- JSON;
- Servidor Backend;
- Web Services;
- Express.js;
- Deploy de APIs no Render.

Uma **API** permite a comunicação entre diferentes sistemas e aplicações.

O **HTTP** é o protocolo utilizado para a troca de informações entre cliente e servidor.

Os principais métodos HTTP são:

- GET — buscar informações;
- POST — criar novos dados;
- PUT/PATCH — atualizar dados;
- DELETE — remover dados.

Um **endpoint** é uma URL específica usada para acessar um recurso ou funcionalidade de uma API.

O **JSON** é um formato leve utilizado para troca de dados entre sistemas.

Também foi apresentado o **Express.js**, um framework para Node.js utilizado para criar servidores Web e APIs REST de forma mais simples.

Na parte prática, foi proposta a criação de uma API com Express, publicação no Render e desenvolvimento de uma aplicação Front-end para consumir essa API.
