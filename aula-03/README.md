# Aula 03 — Projetos com Frameworks Front-end

Na Aula 03 foram apresentados os principais **Frameworks Front-end** e suas características.

Um framework fornece ferramentas, bibliotecas e uma estrutura organizada para facilitar o desenvolvimento de aplicações Web, permitindo criar componentes reutilizáveis e melhorar a manutenção do código.

Os principais assuntos estudados foram:

- Diferença entre Framework e Biblioteca;
- React;
- Angular;
- Vue;
- Next.js;
- Componentização;
- Estrutura de projetos;
- Git e versionamento.

O **React** é uma biblioteca JavaScript utilizada para criação de interfaces através de componentes reutilizáveis.

O **Angular** é um framework completo que utiliza TypeScript e possui recursos como componentes, serviços, roteamento e injeção de dependências.

O **Vue** é um framework progressivo, com sintaxe simples e baseado em componentes.

O **Next.js** é um framework baseado em React que adiciona recursos como roteamento, renderização no servidor e otimizações de desempenho.

Na atividade prática foram propostos projetos utilizando React, Vue, Angular e Next.js para comparar as principais características de cada tecnologia.
